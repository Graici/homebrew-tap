# Graici Tap

## How do I install these formulae?

`brew install graici/tap/<formula>`

Or `brew tap graici/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "graici/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
